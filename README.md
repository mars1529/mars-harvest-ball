# 素材收割球

一个 Windows 桌面小工具：屏幕上常驻一个悬浮球，点一下就把当前正在看的**微信视频号 / 抖音**视频链接抓下来，解析出标题、作者、封面，确认后下载到本机素材库。

> **请先阅读 [免责声明 DISCLAIMER.md](DISCLAIMER.md)** 再使用。本工具仅供个人学习研究，涉及第三方平台登录态，请务必了解其中的合规边界。

## 它能做什么 / 不能做什么

**能做的：**
- 悬浮球常驻，单击抓取当前窗口的视频链接（微信视频号 / 抖音）
- 复制视频链接后自动解析（可开关）
- 弹出小面板预览标题、作者、封面，确认后下载到本机素材库
- 本地素材库浏览、链接历史管理

**不能做的（已刻意阉割）：**
- 不含任何**去字幕 / 云处理 / 账号登录态**逻辑
- 不连接任何第三方 SaaS、不上传你的数据到本项目服务器
- 不含任何打包好的登录凭证、Cookie 或账号信息

## 安装与运行（源码版）

1. **克隆 / 下载本仓库**到本地任意目录（路径不要有中文空格以外的特殊字符更稳妥）。

2. **安装依赖**
   ```bat
   pip install -r requirements.txt
   ```
   确认 `python --version`、`node --version` 都能跑通。

3. **（可选）配置** —— 复制 `config.example.json` 为 `config.json`，按需修改。
   不配置也能直接跑，所有路径默认落在程序所在目录。

4. **启动**
   ```bat
   start.bat
   ```
   首次运行会自动拉起本地后端（只监听 `127.0.0.1`）和悬浮球。
   也可分别手动启动：
   ```bat
   python server.py              :: 终端一：后端
   powershell -ExecutionPolicy Bypass -File ball.ps1   :: 终端二：悬浮球
   ```

## 使用方式

- **单击球**：抓取当前微信 / 抖音窗口的视频链接并解析
- **拖动球**：移动位置
- **右键球**：菜单（抓取、只看微信/抖音、读剪贴板、展开面板、打开素材文件夹等）
- **热键**：
  | 热键 | 功能 |
  |---|---|
  | `Ctrl+Alt+G` | 抓取当前视频（自动判断平台）|
  | `Ctrl+Alt+Y` | 只抓抖音 |
  | `Ctrl+Alt+D` | 读剪贴板里的链接 |
  | `Ctrl+Alt+M` | 展开 / 收起面板 |
  | `Ctrl+Alt+P` | 打开素材文件夹 |

**登录态说明**：解析视频号需要你在**本机浏览器**里已登录对应平台（工具会从本机浏览器读取登录态并在本地缓存，缓存在 `data/harvest/`，不会提交、不会上传）。登录过期时删掉缓存文件、重新在浏览器登录即可。

## 常见问题

**Q: 提示找不到 Python / Node？**
安装后确保加入 PATH，或在 `config.json` 里写绝对路径。

**Q: 抓不到链接？**
先确认视频号/抖音窗口在前台、正在播放一条具体视频；手动复制一次分享链接再试通常更稳。

**Q: 解析失败 / 登录过期？**
在本机浏览器重新登录对应平台，删除 `data/harvest/yb-cookie.json` 后重试。

**Q: 会被提交上去我的账号信息吗？**
不会。`.gitignore` 排除了所有 `data/`、`*cookie*`、`*token*`、`library/` 等。提交前仍建议 `git status` 自查一遍。
